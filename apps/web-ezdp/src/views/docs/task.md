# 任务说明

## 重点
1. 不要参考现有的文档内容，重新梳理一份新的文档内容，也就是完全重构

## 文档要求
1. 根据项目服务端接口和已有的buildAgent代码。来写一份其他人一看就懂的接入文档
2. 页面的布局要符合标准开源项目文档
3. 要做好目录结构，方便用户查阅
4. 内容要全面，包括鉴权方式，server下发的数据格式文档，agent端应该上报的数据格式等等，要全面覆盖Build Agent的接入指南
5. 内容要清晰易懂，适合不同技术水平的用户阅读
6. 文档要包含示例代码和配置示例，帮助用户快速上手

## 开发要求
1. 不要一个文件全部写完
2. 要做好文档路由结构，分模块编写文档内容，要支持锚点定位跳转，方便不同地方跳转到文档页时能正确识别到路由页面
3. 要能方便扩展其他模块的接入指南，比如Deploy Agent等
4. 可以参考一些开源项目的文档设计，或者直接使用开源文档项目框架
5. 最好是使用Markdown格式编写文档内容，构建后转成静态页面展示
